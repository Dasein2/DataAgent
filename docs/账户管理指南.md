# 账户管理指南

## 快速开始

### 查看所有账户
```bash
npm run accounts list
```

### 添加普通用户
```bash
npm run accounts add alice
# 然后按提示输入密码（至少8个字符）
```

### 添加管理员
```bash
npm run accounts add-admin bob
# 然后按提示输入密码
```

### 重置密码
```bash
npm run accounts reset alice
# 输入新密码
# ⚠️ 会使该用户的所有会话失效，需要重新登录
```

### 删除账户
```bash
npm run accounts delete alice
# 需要输入用户名确认
# ⚠️ 无法删除最后一个管理员账户
```

```bash
npm run accounts add alice

```

```
   用户名: alice
```

- ✅ 管理业务上下文
- ✅ 查看和导出结果
- ❌ **不能**修改模型配置
- ❌ **不能**管理提供商
- ❌ **不能**查看系统全局配置

```
创建管理员账户: bob
```

---

### 4. 重置密码

```bash
npm run accounts reset alice
```

**交互过程**：
```
重置账户密码: alice (普通用户)
输入密码（至少8个字符）: ************
确认密码: ************

✅ 密码重置成功！
   已删除 2 个活跃会话，用户需要重新登录。
```

**重要说明**：
- ⚠️ 重置密码会立即使该用户的所有活跃会话失效
- 用户需要使用新密码重新登录
- 用户的历史数据（会话、查询结果等）不受影响

---

### 5. 删除账户

```bash
npm run accounts delete alice
```

**交互过程**：
```
⚠️  警告: 即将删除账户 "alice" (普通用户)
   这将删除:
   - 账户本身
   - 所有活跃会话
   - 该用户的所有会话历史、查询结果等数据仍会保留

输入用户名 "alice" 确认删除: alice

✅ 账户已删除
   已删除 1 个活跃会话

💡 注意: 该用户的历史数据（会话、查询结果等）仍保留在 data/history/ 中
   如需完全清理，请手动删除 ownerKey 为 "account/f23a45bc-..." 的文件
```

**重要限制**：
- ❌ 无法删除最后一个管理员账户
- ⚠️ 删除后无法恢复账户
- 💡 用户的历史数据仍保留在文件系统中

**完全清理用户数据**：
```bash
# 1. 删除账户（获取 ownerKey）
npm run accounts delete alice

# 2. 清理历史数据
cd data/history
grep -r "account/f23a45bc" . | cut -d: -f1 | xargs rm -f

# 3. 清理连接配置
# 编辑 data/connections.json，删除该用户的配置
```

## 用户名规则

**合法用户名**：
- 必须以字母或数字开头
- 只能包含：字母、数字、点(.)、下划线(_)、连字符(-)
- 长度：1-60 个字符
- 不区分大小写（alice 和 Alice 被视为同一用户）

**示例**：
```
✅ alice
✅ bob123
✅ john.doe
✅ admin-user
✅ test_account

❌ _alice      (不能以下划线开头)
❌ alice@      (不能包含 @)
❌ alice bob   (不能包含空格)
❌ alice!      (不能包含特殊字符)
```

## 常见场景

### 场景 1：团队协作


```bash

# 用户使用新密码登录后，建议立即修改密码
```

```bash
# 1. 删除账户
npm run accounts delete alice

# 2. （可选）清理用户数据
# 根据数据保留策略决定是否删除历史数据
```

### 场景 4：管理员交接

```bash
# 1. 创建新管理员
npm run accounts add-admin new-admin

# 2. 验证新管理员可以登录

# 3. （可选）删除旧管理员
npm run accounts delete old-admin
```

## 安全建议

### 1. 密码管理
- ✅ 使用密码管理器生成和存储密码
- ✅ 定期更换密码（建议每3-6个月）
- ✅ 不要在多个服务中重复使用密码
- ❌ 不要将密码写在纸上或文档中

### 2. 账户管理
- ✅ 只给需要的用户分配管理员权限
- ✅ 定期审查账户列表，删除不再使用的账户
- ✅ 新员工入职时创建账户，离职时立即删除
- ✅ 保持至少一个备用管理员账户

### 3. 权限原则
- ✅ 遵循最小权限原则
- ✅ 普通用户足以完成大部分数据分析工作
- ✅ 只有系统管理员才需要管理员权限
- ❌ 不要给所有人都分配管理员权限

### 4. 审计日志
- ✅ 定期检查 data/audit/ 中的日志
- ✅ 关注失败的登录尝试
- ✅ 监控敏感操作（密码重置、账户删除）

## 故障排查

### 问题 1：无法创建账户（用户名已存在）

**错误信息**：
```
❌ 用户名 "alice" 已存在
```

**解决方法**：
```bash
# 1. 检查现有账户
npm run accounts list

# 2. 使用不同的用户名，或先删除旧账户
npm run accounts delete alice
npm run accounts add alice
```

### 问题 2：密码太短

**错误信息**：
```
❌ 密码太短，至少需要8个字符
```

**解决方法**：
- 使用至少 8 个字符的密码
- 建议使用密码管理器生成强密码

### 问题 3：无法删除管理员

**错误信息**：
```
❌ 无法删除最后一个管理员账户
```

**解决方法**：
```bash
# 1. 先创建新管理员
npm run accounts add-admin new-admin

# 2. 再删除旧管理员
npm run accounts delete old-admin
```

### 问题 4：数据库不存在

**错误信息**：
```
❌ 账户数据库不存在。请先启动应用以初始化数据库。
```

**解决方法**：
```bash
# 1. 确保环境变量已设置
export DATA_AGENT_REQUIRE_AUTH=1
export DATA_AGENT_ADMIN_PASSWORD=YourPassword123
export DATA_AGENT_PROFILE_SECRET_KEY=...

# 2. 启动应用一次（会自动创建数据库）
npm start

# 3. 然后使用账户管理工具
npm run accounts list
```

## 数据存储位置

### 账户数据
```
data/
├── accounts.db          # 账户和会话数据库
│   ├── accounts 表      # 用户名、密码哈希、角色
│   └── sessions 表      # 活跃会话 token
```

### 用户数据
```
data/
├── history/
│   ├── sessions/        # 会话历史（按 ownerKey 隔离）
│   ├── tasks/           # 任务记录
│   └── events/          # 事件流
├── results/             # 查询结果
├── artifacts/           # 图表和报告
├── business-context/    # 业务上下文
└── connections.json     # 连接配置（加密）
```

### 数据隔离

每个账户的数据通过 `ownerKey` 隔离：
```
account/e179bc39-ba97-4ea8-9205-46bdbaecfb62  (admin)
account/f23a45bc-1234-5678-9abc-def012345678  (alice)
account/1a2b3c4d-5678-90ab-cdef-123456789abc  (bob)
```

## 高级用法

### 批量创建账户

创建脚本 `scripts/bulk-create-accounts.sh`：

```bash
#!/bin/bash

# 账户列表
users=(
  "alice"
  "bob"
  "charlie"
)

for user in "${users[@]}"; do
  echo "创建账户: $user"
  # 这里需要手动输入密码
  npm run accounts add "$user"
done
```

### 备份和恢复

```bash
# 备份账户数据库
cp data/accounts.db data/accounts.db.backup

# 恢复
cp data/accounts.db.backup data/accounts.db

# 重启应用
npm start
```

### 查看数据库详情

```bash
# 安装 SQLite CLI（如果还没有）
# Ubuntu/Debian: sudo apt install sqlite3
# macOS: brew install sqlite

# 查看账户表结构
sqlite3 data/accounts.db ".schema accounts"

# 查看所有账户（不含密码哈希）
sqlite3 data/accounts.db "SELECT id, username, role FROM accounts;"

# 查看活跃会话
sqlite3 data/accounts.db "SELECT account_id, datetime(expires_at/1000, 'unixepoch') FROM sessions;"
```

## 总结

**创建账户的完整流程**：

1. **确保应用已初始化**
   ```bash
   npm start  # 首次启动，创建 admin 账户
   ```

2. **查看现有账户**
   ```bash
   npm run accounts list
   ```

3. **添加新用户**
   ```bash
   # 普通用户
   npm run accounts add alice
   
   # 管理员
   npm run accounts add-admin bob
   ```

4. **用户登录**
   - 本机默认访问 <http://127.0.0.1:8787/>；若修改了端口，以启动日志为准。
   - 使用用户名和密码登录
   - Session 有效期 7 天

5. **管理账户**
   ```bash
   # 重置密码
   npm run accounts reset alice
   
   # 删除账户
   npm run accounts delete alice
   ```

初始管理员用户名为 `admin`。请使用实际设置的密码，不要将密码写入文档。
